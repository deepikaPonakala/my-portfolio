# 🌐 Personal Portfolio Website

This is my personal portfolio website built using **React.js** to showcase my projects, technical skills, and contact information. It highlights my work in web development and provides an easy way to explore my projects and get in touch.

---

## 🚀 Live Demo
🔗 https://your-portfolio-link.netlify.app

---

## 📌 Features
- Fully responsive design (mobile, tablet, desktop)
- Multiple pages using React Router
- Clean and modern user interface
- Projects section with detailed descriptions
- Skills section highlighting technical expertise
- Contact section with email and social links
- Smooth navigation between pages
